# Mathematical-approaches
This project explores the application of differential privacy using real-world data and evaluates the privacy-utility trade-off through machine learning models. The implementation leverages IBM's diffprivlib to train differentially private logistic regression models on the UCI Adult dataset. Accuracy is measured across varying privacy budgets (ε), illustrating how stronger privacy leads to reduced model performance. The project includes visualizations to demonstrate how privacy affects noise, accuracy, and model behavior, providing a practical supplement to theoretical discussions on data protection. It serves as a practical demonstration aligned with a broader research analysis comparing differential privacy and cryptographic methods.
